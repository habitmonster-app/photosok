사진쏙 v1.5 — 클로드 작업 인수인계

이 파일 묶음은 현재 만든 앱을 클로드에서 이어서 완성하기 위한 전달본입니다.
실행 가능한 웹앱 소스, 대화 요약, 개발 현황, 검증 기록, 외부 라이브러리를 포함합니다.
스토어 등록이 끝난 네이티브 앱이나 출시 승인본이 아닙니다.

먼저 읽을 순서
1. 03_CLAUDE_TASK_PROMPT_KO.txt — 바로 이어서 작업할 요청문
2. 01_CONVERSATION_AND_DECISIONS_KO.md — 사용자가 원하는 것과 변경 이유
3. 02_TECHNICAL_HANDOFF_KO.md — 실제 구현과 남은 문제
4. README.md, docs/product-copy-v15.md — 현재 기능과 소개 문구
5. dist/ 소스와 tests/ — 실제 구현을 기준으로 작업

실행
압축을 풀고 photosok-v1.5 폴더에서 다음 명령을 실행합니다.
  python3 run_local.py
Windows에서 python3 명령이 없으면:
  py run_local.py
브라우저: http://localhost:8000/dist/
검사 목록: http://localhost:8000/tests/
서버 종료: 터미널에서 Ctrl+C
별도의 빌드나 npm 설치 없이 실행됩니다. HTML을 더블클릭하는 file:// 방식은 지원하지 않습니다.
배포할 때는 dist/ 전체를 HTTP(S) 정적 호스팅에 올립니다. tests/는 배포하지 않습니다.

전달 파일
- photosok-v1.5-claude-handoff.zip: 실행에 필요한 전체 프로젝트. vendor/도 반드시 유지하세요.
- photosok-claude-handoff.txt: 대화 요약·인수인계·주요 자체 소스를 한 파일로 읽는 용도.
  TXT에는 용량이 큰 외부 라이브러리, 바이너리, 테스트 전체가 들어 있지 않습니다.
  TXT만으로 완전한 실행 폴더를 재구성했다고 가정하지 마세요. 전체 실행본은 ZIP입니다.
  클로드 채팅에서 ZIP을 첨부할 수 없다면 TXT를 먼저 첨부하고,
  코드 작업 환경에서는 ZIP을 풀어 폴더 전체를 사용하세요.

기준
- UI/기능 버전: v1.5
- 원본 Git 커밋: c51fb130f6a7a4d0de797a463fe05fa366da2a8d
- package.json의 버전 문자열은 아직 1.4.0입니다. 전달본은 이를 임의로 바꾸지 않았습니다.
- dist/는 원본 커밋과 바이트 단위로 동일합니다. 실행 엔진과 디자인을 전달 과정에서 변경하지 않았습니다.
- 일부 검사 파일의 상대 경로만 독립 실행에 맞게 수정했습니다. 변경 목록은 HANDOFF_MANIFEST.json에 있습니다.
- 이전 성능 비교용 v1.2 기준 소스 두 개를 tests/baseline-*.js에 동봉했습니다.
- docs/comparison.md와 docs/positioning.md는 초기 기획 기록입니다. 미지원 기능 설명이 현재와 다를 수 있습니다.
- 대화 자료는 확인 가능한 메시지와 프로젝트를 바탕으로 작성한 요약이며 전체 원문 녹취가 아닙니다.
- 예전 QA 문서의 화면 캡처 파일은 이번 전달본에 포함하지 않았습니다. 앱 자체 SVG 이미지와 테스트용 이미지는 포함합니다.
- Git 이력, 계정/배포 설정, 접근 토큰, node_modules는 전달하지 않습니다.

핵심 주의
현재 앱은 기기 안에서 파일을 처리합니다. 사용자 사진·PDF를 서버에 보내는 구조로 바꾸려면 사용자와 별도로 결정해야 합니다.
실제 iPhone/Android 저장·공유·카메라는 검증이 남아 있습니다.
권리 검토가 끝났다고 표시하지 마세요. 외부 라이브러리 고지와 소스를 유지하세요.
