# 사진쏙 소개 문구 · v1.5

이 문서는 사진쏙의 현재 기능을 기준으로 새로 작성한 소개 문구입니다. 현재 제공 형태는 본인 계정으로 접근하는 웹앱입니다. 앱스토어 출시·모든 휴대폰 지원·무손실 압축·자동 테두리 인식·OCR을 주장하지 않습니다.

## 첫 화면

파일을 보내기 전, 작은 정리

**보내기 전에, 사진쏙.**

사진은 필요한 크기로, 서류는 한 파일로.
저장할 결과를 직접 확인하고 준비하세요.

작업 선택:
- PDF로 모으기 — 페이지·용량 정리
- 사진으로 저장 — 용량 · 크기 · 형식

시작 버튼: **파일 담기**
샘플 버튼: **샘플 서류로 살펴보기**
흐름 안내: 파일 담기 → 저장 조건 고르기 → 결과 확인

## 짧은 소개

사진과 PDF를 보낼 준비. 용량과 크기를 조절하고, 필요한 페이지를 모아 새 파일로 저장하세요.

## 자세한 소개

첨부할 사진과 서류가 여러 개라면 사진쏙에 담아보세요. 필요한 결과를 고르고 저장할 파일을 직접 확인할 수 있습니다.

**사진으로 저장**
사진 한 장의 목표 용량을 고르거나, 가로·세로 크기를 지정하세요. JPG·PNG·WebP 형식으로 새 파일을 만들 수 있고, 지원되는 HEIC 사진도 불러올 수 있습니다.

**PDF로 모으기**
사진과 기존 PDF를 함께 담아 페이지를 정리하세요. 순서를 바꾸거나 불필요한 페이지를 빼고, 회전한 뒤 한 파일로 저장할 수 있습니다. 전체 제한 용량이 있다면 용량 맞추기를 선택하세요.

**서류를 반듯하게**
네 모서리를 직접 맞춰 테두리와 원근을 보정하세요. 적용 전 결과를 살펴보고, 필요하면 보정 전 페이지로 돌아갈 수 있습니다.

파일 처리는 기기 안에서 이루어지며, 처리할 사진과 PDF를 서버로 전송하지 않습니다. 원본 파일을 수정하지 않고 새 결과를 따로 저장합니다. 저장과 공유 지원 여부는 브라우저와 기기에 따라 다릅니다.

## 안내와 한계

- PDF의 ‘용량 맞추기’는 페이지를 사진으로 바꾸므로 글자 검색·텍스트 선택이 사라집니다.
- ‘글자 유지 · 합치기’는 기존 PDF의 검색 가능한 글자를 유지합니다. 사진·스캔본에 OCR을 추가하지 않으며, 용량 제한은 맞추지 않습니다. 입력 양식·전자서명 보존은 보장하지 않습니다.
- 서류 보정은 수동입니다. PDF 페이지를 보정하면 해당 페이지는 사진으로 바뀝니다.
- 파일당 40MB, 원본 합계 200MB, 전체 20페이지까지 처리합니다. 큰 이미지와 HEIC는 처리 한도에 따라 축소되거나 거절될 수 있습니다.
- 촬영정보 제거는 사진 속 글자·얼굴·개인정보 삭제를 뜻하지 않습니다. PDF 글자 유지 모드에서는 기존 메타데이터를 일괄 제거하지 않습니다.
- 원본을 유지한다고 해서 화질이 변하지 않는 것은 아닙니다. 용량 조절 과정에서 품질·해상도가 달라질 수 있습니다.
- 모든 기종이나 파일의 성공, 제출처 심사 통과, 특정 압축률·속도는 보장하지 않습니다.

## 샘플 자료

샘플 풍경은 앱 코드에서 그린 가상 풍경입니다. PDF 샘플은 ‘사진쏙 샘플’, ‘기능 확인용 가상 서류’라고 표시한 가상 확인서입니다. 실제 기관이나 사업자의 서류로 소개하지 않습니다.

## 구현 범위 기록

화면에 쓰는 문구와 모드 설명은 `dist/ui-copy.js`로 분리했습니다. `app.js`의 사진 모드 화면 갱신은 읽을 수 있는 `selectPhotoMode()` 함수로 정리했고, PDF 화면도 같은 문구 모듈을 참조합니다. 압축·PDF·HEIC 처리 엔진이나 제3자 라이브러리를 이름만 바꿔 독자 구현이라고 주장하지 않습니다. 해당 라이선스와 고지는 유지합니다.
