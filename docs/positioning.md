# 사진쏙의 선택 이유

## 약속
서류 사진을 넣고 제출 제한 용량만 정하면, 조건을 확인한 파일까지 한 번에.

처음 공략할 문제는 첨부 용량 초과와 여러 사진을 PDF 한 개로 제출해야 하는 상황이다. 예를 들어 거래명세서 사진 5장을 PDF 한 개, 전체 1MB 이하로 준비하는 작업이다. 사용자가 메뉴·압축 품질을 여러 번 고르는 부담을 줄이는 것이 제품 가설이다.

## 경쟁에서 정직하게 구분할 것
Smallpdf에도 사진→PDF와 목표 1MB 압축 안내, 스캔·OCR·변환·병합 기능이 있다. 사진→PDF 자체는 독점적 차별점이 아니다. 현재 사진쏙은 전체 PDF 편집 도구를 대체하지 않는다.

확인일: 2026-11-09. 앱 버전·기능·요금은 달라질 수 있다.

## 실제 구현한 선택 이유
1. 결과 파일 중심의 시작: PDF 한 개 또는 사진 파일 선택.
2. PDF 전체 용량을 기준으로 자동 처리하고 실제 바이트를 확인.
3. 페이지 순서·회전·작은 글씨를 같은 흐름에서 확인.
4. 사진을 서버에 보내지 않고 위치·촬영정보를 제외해 새 파일 생성.
5. 무리한 축소는 안내하고, 변경 전 결과를 구분해 보관.

사진 속 민감한 글자·얼굴은 제거하지 않는다. 조건 충족 표시는 입력한 용량·형식·페이지 수만 뜻하며, 제출처 접수·내용 적합성·글자 가독성 보장이 아니다.

## 출시 전 우선 검증
같은 서류와 제한을 주고 기존 앱 사용자에게 완료 시간, 잘못 저장한 횟수, 재압축 횟수, 글자 확인, 다음에도 쓸 의향을 비교한다. 아직 사용자 우위나 1위를 입증한 상태가 아니다.

현재 접근은 소유자 전용 미리보기다. 일반 사용자 출시에는 로그인 없는 접근, Android/iPhone 실제 저장·공유 검증, 오류 복구 검증이 필요하다. 기존 PDF 처리와 OCR은 이후 실제 수요를 보고 추가한다.
