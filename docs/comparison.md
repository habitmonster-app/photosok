# 사진쏙 비교 및 v1.1 개선 — 2026-11-09

공식 설명을 비교했으며, 타 앱의 동일 원본 압축률/속도 실험은 수행하지 않았습니다.

| 제품 | 확인한 강점 | 고려점 |
|---|---|---|
| Puma | KB 목표, 픽셀/비율, 자르기/맞춤, HEIC 변환, 전후 비교, 기기 내 처리 | 광고/앱 내 구매; 일괄 처리·EXIF 보존 프리미엄 표기 |
| LitPhoto | 일괄, 자동 별도 폴더 저장, 회전/자르기/공유, EXIF 보존 | 광고 포함 |
| Squoosh | 설치 없이 브라우저 처리, 다양한 코덱/설정, 전후 비교, 사진은 로컬 처리 | 세부 설정 중심; 한국어 제출 규격 흐름을 중점으로 제시하지 않음 |
| 사진쏙 v1.1 | 한국어 단순 UI, 광고·결제 제한 없음, KB+픽셀 함께 지정, ZIP/비교/개인정보 제거 | 현재 소유자 전용 ChatGPT 로그인, HEIC/공유 브라우저 의존, 휴대폰 실기기 검증 필요 |

사진쏙의 장점은 기능 조합과 사용 흐름이며 독점적인 압축 알고리즘이 아닙니다. 푸마와 Squoosh도 사진을 서버에 올리지 않으므로 로컬 처리만으로 차별화를 주장하지 않습니다.

반영: 규격 동시 지정, 촬영정보 제거, 직접 공유, 결과 보존, 모바일 고정 실행 버튼. 잘라내기/편집 도구를 늘리기보다 선택→처리→전송에 집중했습니다.
